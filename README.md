# Markly · 给网页加一层你的思考

Markly 是一款本地优先的 Chrome 网页批注扩展。它可以在普通网页上高亮原文、添加备注、圈画内容，并在独立的标记主页中搜索和管理所有记录。

所有批注都保存在浏览器本地，不需要账号，不上传网页内容，也不包含遥测或云同步。

## 主要功能

- 文字批注：高亮、下划线、删除线和原文备注。
- 页面备注：在网页的指定位置放置备注图标，悬浮阅读，点击编辑。
- 图形工具：自由画笔、矩形、椭圆、箭头、横线、波浪线、双横线和可原位编辑的网页文字。
- 原位编辑：拖动图形，缩放矩形和椭圆，直接修改备注。
- 撤销与重做：每个页面会话保留最近 50 次操作。
- 集中管理：按网页、标题、原文和备注搜索历史标记。
- 本地备份：导出和导入 JSON，便于迁移或定期备份。
- 动态页面适配：支持 SPA 路由变化、开放的 Shadow DOM 和常见的滚动容器。

## 安装

### 使用现成安装包

1. 下载 [`release/markly-0.2.15.zip`](release/markly-0.2.15.zip) 并解压，或直接使用仓库内的 `release/markly` 目录。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的目录。
5. 在 Chrome 工具栏的扩展菜单中固定 Markly。

ZIP 文件不能直接拖入 Chrome，必须先解压。也不要选择项目根目录。

### 从源码构建

需要 Node.js 22.14 或更高版本，以及 pnpm 10.7。

```sh
pnpm install --frozen-lockfile
pnpm build
node scripts/package.mjs
```

构建完成后，加载 `release/markly` 目录即可。

## 使用方法

### 1. 启用 Markly

打开普通网页，点击 Chrome 工具栏中的 Markly 图标。再次点击可隐藏整个批注界面；已保存的批注和未保存的编辑内容不会因此删除。

网页上的绿色铅笔用于展开或收起工具条；列表按钮用于打开当前页面的批注面板。

### 2. 标记文字

选中网页正文后，在弹出工具条中选择颜色，再点击高亮、下划线、删除线或备注。输入框和可编辑区域不会触发该工具条。

### 3. 添加页面备注

选择备注工具，再点击网页中的目标位置。输入内容并保存后，页面上只保留一个小图标：

- 悬浮图标可预览备注。
- 点击图标可编辑备注。
- 按 `Esc` 可取消放置或关闭预览。

### 4. 圈画和编辑图形

在竖向工具条中选择画笔、矩形、椭圆、箭头、线条或文字，然后在页面上操作。线条工具可切换横线、波浪线和双横线；拖动后会保持水平。文字工具会在点击位置直接输入；`Enter` 换行，点击空白处或按 `Ctrl/Cmd+Enter` 完成，双击已有文字可原位编辑。按 `Esc` 返回浏览模式。

浏览模式下可直接点击或拖动图形；矩形和椭圆可通过右下角控制点缩放。选中后按 `Delete` 删除，双击图形或点击“编辑”可修改关联备注。自由画笔不提供节点编辑。

### 5. 查找和管理批注

在当前页面的批注面板中，点击文字标记可跳转到原文。打开“全部标记”后，可以搜索标题、原文和备注，也可以从历史记录重新打开原网页。

如果网页改版导致原文无法唯一定位，Markly 会显示“原文待定位”。在标记操作菜单中选择“重新关联”，再选中新的原文即可。

### 6. 开启站点自动恢复

默认情况下，每次重新打开网页需要再点击一次扩展图标。如果希望某个站点自动加载批注，打开“全部标记与站点设置”，在对应站点选择“允许并启用”。该权限只针对当前站点。

### 7. 备份和恢复

在“全部标记”主页中导出 JSON 备份。导入时：

- 相同 ID 且内容相同的记录会跳过。
- 相同 ID 但内容不同的记录会作为新标记保留。
- 备份格式无效时会整批拒绝，不会写入部分数据。

卸载扩展会删除浏览器中的本地数据，建议在卸载、换电脑或大版本升级前先导出备份。

## 更新扩展

保持扩展的加载目录不变，用新版 `release/markly` 内容覆盖旧文件，然后在 `chrome://extensions` 中点击“重新加载”。不要先卸载，否则本地批注数据会丢失。

## 支持范围

- 支持 Chrome 120 及更高版本中的普通 HTML 网页、图片、`localhost` 和本地 HTML。
- 本地 HTML 需要在扩展详情页开启“允许访问文件网址”。
- Chrome 内部页面、Chrome 应用商店和内置 PDF 阅读器不允许扩展注入。
- 当前不支持跨域 iframe、封闭的 Shadow DOM、Canvas 内的文字和尚未加载的虚拟列表内容。
- Markly 不保存网页快照。原网页删除后，摘录、备注和图形数据仍会保留，但无法恢复原网页。
- 大幅改版、元素移除或复杂布局变换可能导致标记显示“位置待确认”。

## 开发

```sh
pnpm dev                 # 启动 WXT 开发模式
pnpm typecheck           # TypeScript 严格检查
pnpm test                # Vitest 单元测试
pnpm test:e2e            # 加载真实扩展的 Playwright 测试
pnpm check               # 类型检查、单元测试和生产构建
node scripts/package.mjs # 生成可加载目录和 ZIP 安装包
```

首次运行端到端测试前，如果本机没有 Playwright Chromium，执行 `pnpm exec playwright install chromium`。

主要目录：

- `entrypoints/`：后台脚本、页面注入脚本、全部标记页和受限页提示。
- `components/`：React 界面、文字标记、SVG 图形和编辑器。
- `lib/`：文本锚定、几何坐标、数据模型、页面运行时和 IndexedDB 存储。
- `tests/`：单元测试和真实扩展端到端测试。
- `fixtures/`：端到端测试使用的可控网页。
- `release/`：当前版本的可加载扩展和 ZIP 安装包。

## 数据与安全

Content Script 通过受校验的消息接口访问扩展自身的 IndexedDB。网页脚本只能操作当前页面的数据；全局搜索、备份和站点设置只能由扩展页面调用。写入使用事务、幂等操作 ID 和乐观版本检查，避免重试或多标签页编辑造成重复和覆盖。
