# Markly · 给网页加一层你的思考

一个本地优先的 Chrome 网页批注扩展。支持高亮、下划线、删除线、文字与页面备注、自由画笔、矩形、椭圆、箭头、网页文字，以及跨网页搜索和 JSON 备份。

## 安装（不需要运行开发环境）

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择本项目的 **`release/markly`** 文件夹（其中直接包含 `manifest.json`）。
4. 在 Chrome 工具栏的拼图菜单中固定 Markly。
5. 打开普通网页，点击 Markly 图标，即可开始批注。

也可以解压 `release/markly-0.2.7.zip` 后加载解压目录。不要把 ZIP 直接拖进 Chrome，也不要选项目根目录。

**本地 HTML：**在扩展管理页打开 Markly 的“详情”，开启 **允许访问文件网址**。然后用 Chrome 打开 `fixtures/article.html`，点击 Markly。

**自动恢复：**点击面板右上角的“…”（打开全部标记与站点设置），在主页选择“允许并启用”。授权只针对该网站；未授权时，每次重新打开网页需要点击插件。当前标签页的临时启用会在同源刷新后继续生效。

更新时保留相同安装目录，将新构建覆盖到该目录后在扩展管理页点击刷新；不要先卸载。卸载扩展会删除本地数据，更新前建议导出备份。

## 怎么使用

- **划文字：**选中网页正文，选择颜色，再点击高亮、下划线、删除线或备注。输入框和可编辑区不会弹出工具条。
- **写想法：**文字和图形备注默认在原位置显示小图标；悬浮预览，点击编辑，不再自动展开大卡片。点击备注工具，再点击网页内容放置备注；保存后图标留在点击位置，随内容滚动，刷新恢复。Esc 取消放置。
- **圈画：**竖向工具条选择画笔、矩形、椭圆、箭头或文字。Esc 返回浏览。画笔颜色在底部提示条中切换。
- **编辑图形：**浏览模式下直接点击或拖动网页上的图形边线，无需打开右侧列表；矩形和椭圆右下角可以缩放。Delete 删除；双击图形或点击选中后的“编辑”可编辑备注。画笔不提供节点编辑。
- **撤销／重做：**使用工具条按钮；绘图或选中图形时可用 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z。每个页面会话保留最近 50 次操作，刷新后清空撤销记录。
- **找回：**右侧列表点击文字标记跳转原文；“全部标记”中按标题、原文和备注搜索。点击历史标记会打开原网页；若未开启站点自动启用，需要再点一下插件图标。
- **原文变化：**找不到或存在歧义时显示“原文待定位”。打开标记操作菜单，点击“重新关联”，选中新的文字并确认关联。
- **备份：**主页可导出／导入 JSON。同 ID 同内容跳过；同 ID 不同内容保留为新标记。格式错误整批拒绝，不写入部分数据。
- **多标签编辑：**同一条标记在另一标签已被修改时不会覆盖。编辑框保留你的文字，可选择“另存一条”。

## 开发

推荐 Node.js 22.14 或更高版本，pnpm 10.7。依赖版本和 lockfile 已固定。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm test:e2e
node scripts/package.mjs
```

- `pnpm dev`：WXT 开发模式。
- `pnpm check`：严格类型检查、单元测试、生产构建及权限清单检查。
- `pnpm test:e2e`：在**独立临时 Chromium 配置**中加载真实扩展；不使用个人 Chrome 配置。
- `node scripts/package.mjs`：将已构建版本复制至 `release/markly` 并打包 ZIP。
- `node scripts/chrome-smoke.mjs`：macOS 上独立 Google Chrome 配置的本地 HTML 冒烟验收。
- `node scripts/preview.mjs`：macOS 上开启隔离的 Chrome 交互预览，包含演示批注；与用户安装版的数据互不相通。

首次运行浏览器测试，可执行 `pnpm exec playwright install chromium`。测试优先使用该浏览器，也可设置 `CHROMIUM_PATH` 指向 Chromium 可执行文件；本机兼容已安装的 Chromium 1194 缓存。自动化测试只为临时测试配置预授予 localhost 权限，Chrome 原生授权弹窗不是 DOM 自动化覆盖范围。

## 架构

- `entrypoints/`：后台、页面注入、独立标记主页及受限页面说明。
- `components/`：React 界面、SVG 绘图与 CSS Modules。
- `lib/`：锚点、图形坐标、Zod 消息／数据结构和 Dexie 数据库。
- `tests/`：定位与存储单元测试、真实扩展端到端验收。

Content Script 通过消息访问扩展源 IndexedDB。后台核验来源和当前标签页 URL，正文脚本只能操作当前页的数据；搜索全部、备份和站点设置只允许扩展页面调用。写入使用事务、幂等操作 ID 和乐观版本检查，不依赖 Service Worker 常驻。

文本锚点保存原文、前后文、位置、段落和 DOM 提示。目前恢复以规范化原文和上下文消歧为主，DOM 信息作为后续优化提示，不强行按路径猜测。绘图优先绑定内容元素，否则使用文档坐标。文字标记与图形均在插件 Shadow DOM 的 SVG 图层渲染。图层通过手动 Popover 进入浏览器顶层，使用脚本内置的构造样式表；滚动更新独立的几何订阅，不重绘侧栏和编辑器，并按实际包含块裁剪。正文变化时优先复用仍有效的文本范围，失效后再重建索引。带帖子永久链接的内容额外验证帖子身份，避免节点复用后串贴。

## 支持边界

- 目标是普通 HTML 正文、图片、localhost 和本地 HTML。Chrome 120 为声明下限；实际验证环境见 `TEST_REPORT.md`，未宣称测试过所有历史版本。
- Chrome 内部页面、扩展商店、内置 PDF 阅读器不可注入。
- 当前不支持 iframe、封闭 Shadow DOM、画布中的文字，以及虚拟列表尚未加载的内容。开放的 Shadow DOM 已纳入遍历、选区、命中和恢复流程；新挂载的根节点会自动发现。
- 图片缩放可带动相对图形缩放；文字重新排版、跨块图形或元素移除可能显示“位置待确认”。自由笔迹不能保证在任意布局变化后自动贴合。
- 不保存网页快照。原网页删除后仍保留摘录、备注和绘图数据，但无法恢复网页本身。
- URL 保留 query 和 hash；同一篇内容的不同地址按不同页面保存。本地文件移动也会产生新页面身份。
- 无账号、服务器、遥测或云备份。没有无限存储权限；空间不足时保存会报错，应导出备份后整理数据。

视觉与功能验收分别见 `design-qa.md` 和 `TEST_REPORT.md`。

## 0.2.3 工具栏与原位编辑

绿色铅笔负责折叠／展开工具栏，列表按钮单独打开本页批注。选择备注工具，单击正文后在落点旁输入；保存后只留图标。悬浮可以阅读，点击可以编辑，Esc 关闭预览或退出编辑（有修改时提示保留草稿）。

## 0.2.2 定点备注

备注工具和侧栏添加入口均先进入放置模式，点击网页后填写内容。新备注保存内容锚点和点击坐标；旧整页备注没有位置数据，继续从列表查看。

## 0.2.1 交互调整

右侧面板默认收起，添加或编辑备注不会自动展开；点击绿色入口可展开。工具条垃圾桶可以清空当前网页的全部批注，确认后执行，不影响其他网页，无法撤销。

## 更新到 0.2.0

在 `chrome://extensions` 找到 Markly，点击重新加载，然后刷新已经打开的网页。继续使用 `release/markly` 这个加载目录，不需要卸载扩展或清空数据。旧标记保持兼容；旧标记没有记录的新定位信息不会凭空补齐，仍错位时请重新关联文字或重画该图形。

0.2.0 的重构和实际验证边界见 `TEST_REPORT.md`。本次没有成功连接用户 Chrome，chenip.cn 和 X 的真实线上验证仍待完成，不能据此宣称 99% 网页兼容。


### 0.2.0 底层模块

- `lib/runtime/surface.ts`：顶层图层、样式隔离、根节点 zoom 抵消、节点被移除后的恢复、模态窗口上下文。
- `lib/runtime/page-observer.ts`、`geometry-clock.ts`：页面生命周期、开放 Shadow DOM、滚动／字体／动画变化、独立几何订阅。
- `lib/runtime/dom.ts`、`selection.ts`：跨开放 Shadow DOM 的路径与命中、捕获阶段选区事件、键盘选区、局部文本捕获。
- `lib/geometry.ts`：视口、元素未缩放内容坐标、内部滚动与包含块裁剪。
- `lib/runtime/rpc.ts`：后台请求超时，避免界面永久停在“保存中”。写入的操作 ID 仍用于幂等重试。

新绘图使用带版本的元素内容坐标，旧绘图按旧规则读取，不重写旧数据。JSON 导出版本升级为 3，新版同时接受版本 1、2 和 3；旧版插件无法导入新版备份，请勿为了回退界面而降级后编辑这些新图形。
