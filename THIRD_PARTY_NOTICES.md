# Third-party software

Markly uses the following open-source packages. The exact dependency graph is locked in pnpm-lock.yaml. Original license files remain in each installed package.

- React and React DOM — MIT, Meta Platforms, Inc. and affiliates.
- WXT and @wxt-dev/module-react — MIT, WXT contributors.
- Dexie — Apache-2.0, David Fahlander and contributors.
- perfect-freehand — MIT, Steve Ruiz.
- @phosphor-icons/react — MIT, Phosphor Icons contributors. The extension icon is rendered from the PencilSimple icon in this package.
- Zod — MIT, Colin McDonnell and contributors.

All runtime resources are bundled locally. The sample article is a local test fixture; the user's reference image is used only as design review evidence, not embedded in the extension.
