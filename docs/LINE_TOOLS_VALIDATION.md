# 线条工具（0.2.13）

日期：2026-11-06。

新增 line / wave / double 三种 Drawing.tool。通过统一选择器进入绘图，不改变其他工具入口。单线/双线按起笔水平锁定，波浪线使用确定性三次贝塞尔曲线，不依赖手速或 pointermove 密度。双线为 y±3px 两条平行线。现有 Shape 同时用于图标预览、手势预览、正式呈现及透明点击命中区域。

复用元素锚定、内容身份检查、手势所属指针、滚动取消、保存队列、撤销及多标签协议。线条移动时保持类型；列表与全部标记页显示对应名称。选择器记住用户样式；箭头键选项切换、Esc 退出菜单，点击外部关闭。

备份导出版本 5，旧版本 1/2/3/4 继续可导入。未改变数据库版本或旧批注。

验证：严格类型检查、生产构建、33 项单元测试通过。既有 26 组扩展回归通过；新增线条流程验证三种样式、从右向左拖动、水平锁定、撤销重做、移动、刷新恢复、样式记忆与真实鼠标点击删除。水平 SVG path 的包围盒为零高度，测试通过鼠标坐标点击透明笔画区域而不是依赖 locator.click 的非零高度判定。
