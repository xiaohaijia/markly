# 0.2.9 原位文字验证

日期：2026-11-05。

文字工具改为原处透明输入。Enter 换行，点击空白处或 Ctrl/Cmd+Enter 保存；新文字为空时 Escape 取消。保存失败保留编辑并提供重试。旧文字双击编辑，移动时保留文字宽度。

新增 drawing.textWidth 可选字段，保证 SVG 按输入宽度恢复换行。导出版本为 4，导入兼容 1/2/3/4，旧批注不清空、不重写。

验证结果：类型检查、生产构建、29 项单元测试通过。完整 22 组 Chromium 回归通过，另增加并通过 1 组原位文字自动保存写入故障测试。覆盖多行、emoji、IME 合成事件、点击空白保存、重新编辑、刷新、边缘换行、空内容取消、失败保留及幂等重试。IME 使用事件模拟，尚未穷尽系统输入法。

回归同时修复滚动事件尚未派发就松手的竞态：手势按起笔时的几何快照验证，滚动或布局变动后不提交混杂坐标。

没有新增线上站点兼容率声明，架构审查中的持久提交队列、后台版本号及大页面性能工作仍未完成。

## 0.2.10（2026-11-06）

文字的 points 只有基线落笔点，不能用作字形边界。改为选中时用 SVG getBBox 测量实际渲染的文字；字体加载、布局更新、移动及内容变更后重新测量。选框包含 6px 留白，不拦截鼠标。

29 项单元测试、严格类型检查和生产构建通过；4 组相关 Chromium 测试通过，包含新增的选框坐标/尺寸断言、拖动、双击编辑、补写多行及刷新后重新选中。
